# V11.2 帳號頁與帳號選單

## 已批准行為

- R／U／I 已確認；右下頭像與「帳號」文字組成單一帳號卡片，卡片任何位置第一次點擊都開帳號選單。
- 未登入時卡片文字顯示「帳號」；登入後改顯示既有 AuthorProfile 的筆名。筆名空白時保留「帳號」，長筆名單行截斷。
- 帳號選單最上方的「帳號」項目在主內容區開新頁，頁內包括筆名、簡介、帳號名稱（Email）及使用方案；筆名／簡介直接編輯並保存到既有 AuthorProfile，Email 只顯示登入帳號，未登入顯示「尚未登入」。既有頭像編輯保留於同頁。
- 帳號選單另包含登入、切換帳號、登出、設定。帳號操作處理中停用；未登入停用切換與登出，已登入停用登入。切換帳號成功登出後才開既有 Email OTP 表單，失敗留錯誤、不開表單。
- 移除側欄獨立「關於我」及其舊彈窗入口。帳號選單沿用卡片 Anchor 定位與外部空白取消；帳號頁不以彈窗呈現。
- 方案維持既有記憶體選項；本輪不連接付費、同步或建立資料隨 Email 切換機制。主 schema 及安全儲存政策不變。
