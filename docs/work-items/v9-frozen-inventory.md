## 目標、完成條件、範圍與非目標

- 目標：以 [固定盤點基準](../v9-freeze/README.md) 管理所有 V9 共用化命中點，按「已共用／待共用／合理例外」和證據完成決策，不再逐個新發現便擴大 V9。
- 完成條件：固定 2,256 筆呼叫點與 93 個模組複核完畢；待共用項目處置與驗收對得上 ID；結案門檻全部滿足。
- 範圍：按鈕、欄位、編輯器、背景、圖標、文案、輔助描述、重複提示、錯誤路徑及模組責任。
- 非目標：因單一新命中點增加 V9 範圍、機械替換所有 SwiftUI 原生控制、改動未核定的 UI 或資料政策。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求凍結基準、完整逐項清單、三態理由、禁止單點自動擴張及明確結案門檻。 |
| U | not_applicable | 本工作單只建立固定清單與處置程序；具體 UI 修改沿用各工作單 U 狀態。 |
