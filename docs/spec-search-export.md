# 查找、替換與匯出功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-09-18

## 1. 查找與替換

- 查找範圍可選「本節次」或「全書」。
- 查找不區分大小寫。
- 可逐筆查看上一筆／下一筆結果。
- 啟用替換後，可替換目前結果或全部替換。
- 替換會保留被替換文字原本的格式屬性，並更新節與書籍的更新時間及字數。
- 替換後應重新整理結果，避免繼續操作過期位置。

## 2. TXT 匯出

- 可匯出整本書、單卷或單節。
- 匯出內容包含標題、作者、簡介（整本書）及依卷節順序排列的正文。
- TXT 內容的所有 `#` 字元均移除（包括標題文字本身及幕標題前綴）。書名為一般文字，卷名格式為「第X卷 卷名」（例如「第一卷 霧港」），節名預設格式為「第一節 標題」。
- 編輯器的幕標題保留文字，不輸出 Markdown 井字號前綴。
- 匯出使用原生存檔面板，作者可選擇檔名與目的地；取消不寫檔，既有檔案的覆寫確認交由系統處理。
- TXT 與 EPUB 使用 SwiftUI `fileExporter` 搭配 `FileDocument` 顯示系統輸出面板；產品匯出路徑不得直接建立 `NSSavePanel`，避免偵錯執行在面板初始化時觸發 AppKit breakpoint。
- App Sandbox 的 Debug 與 Release target 都必須啟用使用者所選檔案的讀寫 entitlement；唯讀 entitlement 會令 SwiftUI 內部建立輸出面板時觸發 `REPORT_APP_ENTITLEMENTS_INSUFFICIENT`。
- 寫入失敗顯示可理解的錯誤；成功後可由 Finder 定位成品。

## 3. EPUB 匯出

- 可將整本書匯出為 EPUB 3 結構。
- 內容包含封面頁、導覽目錄、卷與節、樣式及書籍標題／作者中繼資料。
- 卷與節依目前排序輸出。
- 匯出會嵌入畫面目前顯示的封面 PNG：有自訂圖片時讀取目前 UUID 對應檔案，否則產生同色彩與首字的預設封面；以 OPF `properties="cover-image"` 宣告並在封面頁等比例完整顯示，封面頁與閱讀器書庫縮圖使用同一圖片。
- 自訂封面缺失、無法解碼或被移除時回到預設首字封面；只有預設圖片生成也異常時才使用書名／作者文字封面，且不得阻止正文匯出。

## 4. 待確認決策

- 故事標籤、大綱、設定集資料是否要匯出。
- TXT 是否完整遵循 Markdown 標記慣例。
- EPUB 是否需要版權與其他中繼資料。
- 全部替換是否需要預覽、撤銷或再次確認。
