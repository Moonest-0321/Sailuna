## 登入界線

- Guest 保留首頁書櫃、建立／匯入書籍、正文、角色及設定等本機創作。首頁的創作入口不能因網路或 Session 失效而停用。
- 尋找、發布、模板、論壇、成就、帳號資料等非創作頁面要求目前工作區帳號與有效 Session 的 user UUID／環境相符；僅選了本機帳號位置不足以解鎖。Guest 進入時顯示「登入後可使用」與登入入口，登入後回原目標；登出或切換到 Guest 時即重鎖。
- 已選本機帳號但 Session 確實缺失或失效時，論壇與帳號選單的「登入」直接開既有 Email OTP 表單（含必要的鑰匙圈重試），完成後返回原頁；Guest 且本機已滿兩帳號仍先進資料空間選擇。暫時無法續期的網路錯誤只顯示可重試的服務錯誤，不直接抹掉已驗證的帳號身分；社群遠端操作仍須成功取得有效 Session，工作區與 user UUID 必須相符。
- 2026-10-06 帳號切換修正：兩個已登入帳號各自保存鑰匙圈 Session，切換與啟動恢復目前帳號的登入，不以另一個帳號的單一 Session 代替。切換後論壇使用所選帳號的 client；上一帳號延遲續期／錯誤回呼不能重設目前登入身分。舊版已被覆蓋的 Session 無法重建，該帳號須補 OTP 一次；新保存後有效登入可往返切換。契約與驗收見 `spec-workspaces-v11.5.md`。
- 帳號卡片、登入與切換帳號始終可用；設定頁的章節單位等創作選項可在 Guest 使用。
- **目前已接線**：`ContentView` 側欄登入提示、`WorkspaceCoordinator.canUseSignedInFeatures` 工作區／Session 比對、兩處 TXT／EPUB 匯出入口的登入檢查，以及模板／論壇 service 每次遠端操作前的 Session 驗證。正式資料庫權限仍須套用 migration，畫面閘門不能代替 RLS。

## 共享模板

- 作者於「我的模板」選擇本機快照，預覽公開內容並確認後才上傳。公開快照可含設定、角色、地圖、時間軸與 PDF 地圖資產，不含正文；建立本機模板不自動公開。
- 「搜尋模板」只顯示已公開模板，已登入者可搜尋、查看作者／摘要／版本及使用模板建立獨立本機草稿。取消公開使遠端不再可讀，不刪本機模板；同一作者再次公開同一快照可解除隱藏。失敗保留本機檔並可重試。
- **程式與資料庫已接線**：拾頁 migration 副本、RLS 與資料庫測試，帆夢上傳／下載／取消公開及搜尋／套用 UI；正式 SQL Editor 已套用，跨帳號共享尚未驗證；`BookTemplateStore` JSON 與備份維持本機契約。

## 共用論壇

- 保留五分類與純文字標題／內文。登入者手寫新文後發表到共用論壇；列表顯示作者與時間。一般文章只准作者改／刪；官方公告只有管理員可發表／改／刪，所有已登入者可讀。
- 舊 `Forum Posts.json` 是本機私有文章，不自動上傳、混入共用列表或在更新時刪除，備份／還原維持原契約。送出失敗保留編輯內容，不標示已發表。
- **程式與資料庫已接線**：拾頁 migration 副本、RLS 與資料庫測試，帆夢共用論壇讀寫 UI 與 service；正式 SQL Editor 已套用，跨帳號共享尚未驗證。留言、按讚、圖片與舊文自動遷移不在本版。

## 驗收界線

兩個獨立帳號／安裝對同一後端看見同一篇已發表文章與公開模板；匿名、跨帳號與非管理員的違規直接呼叫被服務端拒絕；取消公開後不能以舊 ID 讀取；本機模板／文章與備份不因遠端故障遺失。App 編譯、替身測試或訪客登入提示均不能取代此真實串接驗收。

2026-10-06 登入切換修正已真實驗收：同一正式 App 的兩個有效帳號往返論壇、退出重開再切帳號，均保留登入，並可讀同一既有公告；Guest 仍鎖論壇。這只完成登入持續保存與同一安裝跨帳號讀取，其他安裝／寫入／取消公開驗收仍保留。Email 登入完成後目前會重建根工作區而回首頁，與上方「返回原目標」有差異，產品意圖／UI 調整仍待確認，不能當作這項已通過。
