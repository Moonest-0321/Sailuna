# V9.1ae 故事線、關係與匯出操作語意資源

> 狀態：closed
>
> 工作單位：將目前相同語意、相同字形或文字的重複畫面呼叫接入共用資源。

## 現況與範圍

- 故事線圖標 `point.topleft.down.to.point.bottomright.curvepath` 共四處，均表示故事線或其空狀態。
- 關係圖標 `point.3.connected.trianglepath.dotted` 共三處，均表示角色關係或關係網。
- 書籍總覽與編輯工作區各有「匯出 TXT」「匯出 EPUB」入口；相同匯出動作目前已統一 TXT 圖標，但兩種可見文案及 EPUB 圖標仍直接散寫。
- 本批新增 `storyLine`、`relationship`、`exportEpub` 圖標語意鍵，以及兩種匯出文字鍵；只替換九個直接圖標呼叫點與四個匯出文案呼叫點。圖形、繁體中文、位置、匯出流程及資料不變。

## 非目標與例外

- `book.closed` 在「找不到這本書」空狀態表示書籍，不是匯出 EPUB，保留獨立用途。
- 不將其他同字形但不同語意的圖標、狀態或資料類型機械併入。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求相同功能使用相同圖標與敘述文字，並統一呼叫程式碼。 |
| U | not_applicable | 僅集中資源來源，畫面字形、文字與位置不變。 |
| I | approved | V9 既有共用圖標／文案採用模式已核定；本批逐呼叫點核對語意。 |

## 完成條件

- 九個圖標呼叫點及四個匯出文字呼叫點均引用共用資源；直接字串保留語意例外。
- String Catalog 兩個鍵的繁體中文值與原文相同。
- `git diff --check`、Catalog JSON 語法與主機無簽章 Debug build 通過；不新增或執行 XCTest。

## 結果

- 新增 `.storyLine` 四處、`.relationship` 三處及 `.exportEpub` 兩處語意圖標採用；字形仍分別是既有故事線、關係網及 `book.closed`。
- 書籍總覽與編輯工作區各兩個匯出入口使用 `SailuneActionCopy.exportText`／`.exportEpub`；String Catalog 繁體中文分別維持「匯出 TXT」「匯出 EPUB」。
- `book.closed` 的「找不到這本書」空狀態保留直接字形，不冒充匯出操作。
- Catalog JSON 語法、`git diff --check`、主機無簽章 macOS Debug build 通過。`SailuneSymbol` 靜態引用由 165 增至 174，直接 `systemName`／`systemImage` 字串由 117 降至 108。未執行 XCTest 或 GUI 驗收。
