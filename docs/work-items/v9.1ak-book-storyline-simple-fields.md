# V9.1ak 書籍與故事線單行欄位共用接線

> 狀態：closed
>
> 工作單位：接入五個相同的圓角單行欄位，同時保留書籍建立、總覽編輯與故事線改名流程。

## 範圍與非目標

- `ContentView` 新建書籍的書名與作者、`BookOverviewView` 總覽的書名與作者、`OutlineViews` 故事線名稱，均使用原生 `TextField` 加 `.roundedBorder`。
- 五處改用 `SailuneFormTextField`。原 title、Binding、Enter 提交、書籍 `updatedAt`、故事線字級及父層排列保留。
- 不改資料驗證、保存、焦點、輸入高度、圓角或顏色；總覽簡介是垂直多行，改名欄有焦點與提交語意，留作專用欄位。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者要求重複單行欄位呼叫共用程式碼。 |
| U | not_applicable | 共用元件仍渲染相同原生欄位與圓角 style。 |
| I | approved | 五處僅替換欄位建構式，外層修飾與資料流程不變。 |

## 完成條件

- 五處標題、Binding、提交及更新順序與原畫面一致。
- 主機無簽章 macOS Debug build 與 `git diff --check` 通過；不新增或執行 XCTest。
- Light／Dark、焦點及首行距離仍待 V9.1x 實際畫面核對。

- 主機無簽章 macOS Debug build 與 `git diff --check` 通過。共用單行欄位 37 處、精確原生 `TextField(` 67 處、`.roundedBorder` modifier 30 處（靜態命中）。
