# 發布書籍數據頁

## 頁面流程

- 發布列表點擊書名進入該書數據頁；發布／完結仍是原本獨立狀態操作。
- 數據頁提供「返回發布」，保留左側導航。內容依序為創作者與讀者，超出視窗時垂直捲動。
- 創作者區顯示今日編輯字數與近一週編輯淨字數。讀者區顯示今日閱讀數，並按序呈現每日閱讀數、每日保有書櫃讀者數、每日追更率與每日收益圖表。
- 每週範圍依裝置目前本地 Calendar，含今天及前六個日曆日。

## 數值定義與空值

- 編輯字數沿用編輯器字數定義（正文非空白字元數），每日值為當日每次成功保存正文後的字數差額加總，可為負數。
- 編輯器防抖保存與 flush 同一內容只記一次；保存失敗不記錄。作者明確執行搜尋取代亦在保存成功後記錄。自動引用同步、資料修復、匯入與書籍／章節刪除不計入每日編輯量。
- 僅記錄有成功保存事件的日期；該日已記錄而淨額為零顯示 0。無歷史基線、當日沒有保存事件或統計不可用時留白，不以現況回算。
- 讀者數據沒有本機或平台來源，因此指標標題與日期軸呈現，數值及線條留白。追更率口徑為「閱讀至最後一節讀者數 ÷ 加入書櫃讀者數」；保有讀者數為「前日持有＋當日新增－當日離開」。無來源時不計算。
- 缺值日不畫點或線，也不以零補值；折線只連接相鄰的有值日期。收益單位依資料來源決定，本版沒有來源所以不顯示單位或數值。

## 持久化與相容性

- 編輯統計以獨立 `Sailune/Writing Stats.json` sidecar 保存，鍵為書籍 UUID 與裝置本地 `yyyy-MM-dd` 日鍵；不變更已發布的 `NovelWriterSchemaV5`。
- 完整備份選擇性加入 `writing-stats.json`；驗證格式與 checksum。還原包含 rollback；舊備份缺少該檔時清除目前統計，對應日期回到空白。
- 書籍永久刪除後移除該 UUID 記錄；清理錯誤需顯示給作者。
- 正文和統計 sidecar 是不同儲存交易。正文成功而統計寫入失敗時保留正文，當次啟動受影響書籍的統計停用並顯示錯誤，不把缺值轉成 0。若程式在錯誤後關閉，失敗旗標沒有可寫位置持久保存，重開可能無法辨認少記；此為已知限制。

## 驗收

- 書名可進入及返回專屬數據頁，發布狀態操作行為保持原樣。
- 今日值與七日圖依本地日顯示；有效 0、正值及負值能區分；未知日期空白，圖表不跨過空值連線。
- reader 指標沒有來源時全數留白。
- 重開後統計保留；刪書清除該書資料而保留其他書；新備份還原復原統計，舊備份還原清除現存統計。
