# V9.1b 重複表面色集中

> 狀態：closed（24 個呼叫點已統一使用 token）
>
> 工作單位：把完全相同的淺層背景色改由單一語意 token 提供。

## 目標與完成條件

- `Color.secondary.opacity(0.06)` 只在 `SailuneTheme` 定義一次；原先使用此顏色的畫面統一呼叫該 token。
- 只替換色彩來源，不改圓角、padding、控制位置、命中區、資料行為或其他顏色。
- 確認所有原字面值使用點均已遷移，並檢查變更差異沒有擴大範圍。

## 範圍與現況

- 2026-09-23 靜態盤點：六個功能 View 檔共有 24 處完全相同的 `Color.secondary.opacity(0.06)`，用於列或卡片的低對比背景；其中一處是無圓角的列背景，其餘在各自的形狀內使用。
- 變更範圍為 `Sailune/SharedUI/SailuneUIFoundation.swift` 的 token 定義，以及 `CharacterHistoryViews.swift`、`CharacterSectionViews.swift`、`InspectorViews.swift`、`OutlineViews.swift`、`TimelineViews.swift`、`V5SettingViews.swift` 的直接替換。
- 不將其他透明度、不同系統色、選取色或資料視覺化色彩合併到此 token。
