## R／U／I 與邊界

- R：approved。使用者要求相同功能使用相同敘述文字，並要求按凍結逐項清單處理剩餘項目。
- U：not_applicable。本批只統一字串來源，繁體中文顯示文字、位置、按鈕角色和互動不變；`新增副本` 兩處圖標差異另依 symbol／button ID 審核，不能夾帶修改。
- I：approved。使用者已指示按固定清單完成剩餘項目；本批以 `SailuneActionCopy` 為單一來源，保留所有原 closure、Binding、role、style、禁用與提示。
- 非目標：合併不同領域的資料操作、改字、改圖標、改命中或改 SwiftData schema。
