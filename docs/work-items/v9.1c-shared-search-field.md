# V9.1c 共用搜尋欄位歸位

> 狀態：closed（共用搜尋欄位已歸位且七個呼叫點已更新）
>
> 工作單位：將已跨功能使用的搜尋欄位移入 `SharedUI` 並統一呼叫名稱。

## 目標與完成條件

- 將 `InspectorSearchField` 的既有 View 實作移至 `SharedUI`，命名為 `SailuneSearchField`；物品、能力、角色、勢力、地點、世界條目與標籤的七個呼叫點使用同一型別。
- 保留原有 placeholder、Binding、清除按鈕、padding、背景形狀、輸入與焦點行為。
- 搜尋圖標、清除搜尋圖標及搜尋欄底色由 `SailuneSymbol`／`SailuneTheme` 定義，實際圖形和色值不變。
- 靜態核對七個呼叫點、原型別移除及差異範圍。

## 範圍與非目標

- 修改 `Sailune/InspectorViews.swift`、`Sailune/V5SettingViews.swift`、`Sailune/StoryTagViews.swift`、`Sailune/SharedUI/SailuneUIFoundation.swift`。
- 不把其他搜尋欄、文字欄或特殊 `CompositionAwareTextField` 一併遷移；它們仍需逐項核對提交、組字和焦點差異。
- 不改搜尋過濾邏輯、資料來源、顯示文字、命中區或可見排列。
