# V9.1ai 能力詳情單行欄位共用接線

> 狀態：closed
>
> 工作單位：將能力詳情頁五個相同的原生圓角單行欄位接入共用元件。

## 現況、範圍與非目標

- `AbilityDetailView` 的能力名稱，以及等級名稱、能力描述、代價、其他四欄，均為 `TextField` 加 `.roundedBorder`，沒有專用 focus、submit、數字過濾或多行設定。
- 五欄改呼叫 `SailuneFormTextField`；該元件內仍是相同的原生 `TextField` 與 `.roundedBorder`。
- 保留各欄標題、Binding、順序、外層 GroupBox／VStack／HStack、`updatedAt` 更新及資料操作。不調整高度、顏色或圓角，也不宣稱解決尚未定位的首行穿模。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者要求相同填寫欄位由統一程式碼提供並呼叫。 |
| U | not_applicable | 原生欄位及圓角 modifier 由共用元件原樣提供，畫面與互動不變。 |
| I | approved | 五處只替換欄位建構式，其他修飾與資料流程不動。 |

## 完成條件與驗證

- 五處接入共用元件；逐欄核對標題與 Binding，以及四個等級欄位的 `updatedAt` 更新。
- `git diff --check` 和主機無簽章 macOS Debug build 通過；不新增或執行 XCTest。
- 實際焦點、組字、首行安全距和 Light／Dark 畫面仍列於 V9.1x 驗收，不能由建置結果推定。

## 結果

- 五處均已接入 `SailuneFormTextField`；原標題、Binding、排列、`updatedAt` 更新與刪除動作保留。
- 初次建置發現元件建構式需要 `title:` 標籤，補正後主機無簽章 macOS Debug build 通過；`git diff --check` 通過。
- 全專案共用單行欄位採用數為 26；精確原生 `TextField(` 命中 78、`.roundedBorder` modifier 命中 41，僅為靜態計數。未執行 XCTest 或 GUI 驗收。
