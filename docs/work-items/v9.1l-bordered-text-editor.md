# V9.1l 設定頁共用邊框多行編輯器

> 狀態：closed（六個相同編輯器已接入）
>
> 工作單位：讓六個完全相同的原生 `TextEditor` 邊框組合使用同一個共用 variant。

## 目標與完成條件

- 在 `SharedUI` 提供 `SailuneBorderedTextEditor`：`TextEditor`、原 `frame(minHeight:)`、8 pt `RoundedRectangle` 邊線；邊線顏色引用既有同值 `SailuneTheme.textEditorBorder`。
- 將 `V5SettingViews.swift` 六個相同組合接入；保留原 Binding、72／90 pt 最小高度、字體繼承、原生編輯器背景、捲動、focus 與後續資料操作。
- 不修改 `AppearanceRow` 的 `InsetTextEditor`、正文 AppKit 編輯器、其他外觀不同的編輯器或產品文案。
- 靜態核對六個呼叫點及原實作的順序，通過差異檢查與主機 Debug build。

## R／U／I

| 關卡 | 狀態 | 依據 |

| U | not_applicable | `TextEditor`、frame、overlay 及顏色值維持原樣，沒有新的畫面排列或互動提案。 |

## 驗證與風險

- 2026-09-23：六個 `V5SettingViews.swift` 呼叫點均使用 `SailuneBorderedTextEditor`；原始 `frame(minHeight:)`、overlay 圓角及色值移入共用程式碼，Binding 及最小高度保持原值。
- 2026-09-23：`git diff --check` 與主機無簽章 Debug build 通過。本批未執行 GUI 或程式測試；編譯與靜態差異不能證明 CJK 組字和焦點完全等價，這些仍列入 V9 UI 驗收。
- `InsetTextEditor` 具有額外內距、底色及隱藏捲動背景，不能與本 variant 合併。
