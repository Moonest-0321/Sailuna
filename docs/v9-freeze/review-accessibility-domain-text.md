# V9 輔助描述的領域例外複核

以下 ID 仍由畫面本身持有文字，因為描述包含該畫面的對象、輸入方式或精確數值；把它們改成通用操作詞會失去資訊。這是來源分類，hover／VoiceOver 實際驗收仍未完成。

| 固定 ID | 來源證據與保留理由 |
|---|---|
| V9-0116、0117 | 書籍封面在右鍵選單更換；AX 名稱指出目標是封面，hint 指出右鍵方式，兩者用途不同。 |
| V9-0130 | 書籍總覽的故事背景展開動作；hint 明確指出會編輯整本書背景。 |
| V9-0147 | 總覽匯出選單有 TXT／EPUB 兩格式；help 提醒選格式，不能只用通用「匯出」。 |
| V9-0195 | 書卷排序把手的拖曳提示；沒有相同契約的 Button，手勢另見整類漏項提案。 |
| V9-0207、0208 | 角色敘事版本控制：AX label 是對象名稱，help 是設定動作，兩種語意刻意不同。 |
| V9-0211、0212 | 角色時間序版本控制：同上，並與敘事版本區分。 |
