# V11.2 帳號呈現

> 前輪登入／稱號呈現細節為未批准草案；使用者目前只批准定位校正：彈窗以帳號按鈕實際上緣為下緣基準，保留 8 pt 間距，高度不足才捲動。

- 登入方式只提供既有 Email OTP；不呈現 Apple 登入或其佔位訊息。
- 登入後，側欄與帳號彈窗使用本機 AuthorProfile.penName 作稱號。筆名去除首尾空白，未填顯示「尚未設定筆名」；不以 Email 替代稱號。Email 在彈窗作次要帳號識別，未改遠端作者資料。
- 帳號彈窗由父容器統一決定寬度，最多 300 pt 並保留視窗內邊界；高度依父容器可用範圍約束，過長改為捲動。筆名最多兩行，Email 單行中間截斷且可選取。
- 方案 Picker 不重複繪製已選文字。點擊彈窗外空白關閉且攔截背景操作。
- 驗收狀態：parse／無簽章 Debug build 通過；登入前後、長文字、小視窗捲動及空白命中 GUI 驗收尚未完成。

## 定位修復驗證

- 定位以帳號按鈕 bounds Anchor 在父 overlay 同次 layout 解析，不回存 CGRect 至 State。
- 2026-09-29 最新隔離 App 實際驗收：未登入可開啟、貼近按鈕上緣、點空白取消、再次開啟。登入後高度與小視窗捲動尚未驗證。
