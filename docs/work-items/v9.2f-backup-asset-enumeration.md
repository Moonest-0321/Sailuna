# V9.2f 備份資產列舉失敗回報

> 狀態：closed（資產目錄存在時的列舉錯誤已傳遞）
>
> 工作單位：讓「建立完整備份」在封面或地圖資料夾存在但無法列舉時停止，不產生漏檔但看似成功的備份。

## 目標與完成條件

- `SailuneBackupService.makeArchive` 先確認封面／地圖資產目錄是否存在；不存在時維持既有零資產結果，存在時用可拋錯的列舉 API 讀取檔案。
- 列舉成功後的 PNG／PDF 篩選、相對路徑、資料讀取、manifest 與 checksum 保持原邏輯；AI 對話目錄原本已採存在檢查加 `try`，不變。
- 目錄存在但列舉失敗時，`createBackup` 經既有 throwing API 回報到 `AuthorSettingsView` 的備份錯誤出口；不更動成功備份、還原、schema 或 UI 文案。
- 逐點核對兩處 `try?` 已移除，通過差異檢查及主機 Debug build。故障注入與備份／還原測試未授權執行，列為待驗證。
