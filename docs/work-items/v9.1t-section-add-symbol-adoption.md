# V9.1t 新增節圖標語意統一

> 狀態：closed（5 個「新增節」呼叫點已使用同一語意 key）
>
> 工作單位：集中同一「新增節」操作目前重複指定的 `doc.badge.plus` 圖標字串。

## 目標與範圍

- `BookOverviewView` 與 `EditorWorkspaceView` 中五個標籤相同的「新增節」入口使用一個明確的圖標語意 key。
- 保留現有可見圖形、繁體中文標籤、action、位置與 Button style。
- 不合併其他 `doc.text`、`plus` 或導覽圖標；它們在匯出、空狀態、內容類型等情境有不同功能。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者要求同功能使用相同圖標，並由相同程式碼統一呼叫；五處文字與 action 均為新增節。 |
| U | not_applicable | 原 SF Symbol、標籤、版位和互動不變，只將字串改由語意表取得。 |
| I | approved | 屬 V9 明確核准的共用符號採用範圍；不改產品行為。 |
