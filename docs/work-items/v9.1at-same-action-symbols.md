# V9.1at 同功能圖標的兩個不一致點

> 狀態：active；R approved、U approved、I approved（使用者同意統一圖標，並已要求依固定清單完成剩餘項目）；固定 symbol ID V9-0789（新增副本）及 V9-2131（刪除事件卡片）。

## 實際差異

- 物品詳情與副本詳情都呼叫 `addCopy`、顯示「新增副本」；前者用 `plus.square.on.square`，後者用共用 `.add`（`plus`）。提案兩處保留位置與文案，統一使用具名 `.addCopy`，字形採更能區分「複製一個副本」的 `plus.square.on.square`。
- 時間軸事件卡片的刪除 Button 呼叫 `onDelete`、help 是「刪除事件卡片」，字形 `xmark.circle.fill`；同功能的事件刪除入口使用共用 `.delete`（`trash`）。提案卡片保留按鈕位置、尺寸、action 與確認流程，字形改成 `.delete`。

## 文字線框與驗收

- 物品兩個「新增副本」入口：原位置 `［副本圖標＋新增副本］`，相同圖標；不改副本建立或保存。
- 事件卡片右側：原位置 `［事件內容］［刪除圖標］`，圖標改用刪除語意；不改可點範圍、確認、資料操作與 help。
- U 核定後才改可見圖形；I 須另外核定具體受影響兩檔、無 schema 變更、build 及 Light／Dark／hover／VoiceOver／實際命中驗收。2026-09-25 已接入 `.addCopy` 與 `.delete`，主機無簽章 Debug build 通過；Light／Dark、hover、VoiceOver 與實際命中待驗收。
