# V10.4 社群模板、書籍發布標籤與導覽對齊

> 狀態：R／U／I approved；依使用者確認開始實作。

## 目標與現況

修正社群子項目文字對齊；發布時選擇並顯示作品標籤；從既有書籍建立設定／大綱／地圖模板，再從模板建立首頁草稿。

- 「模板」目前是佔位頁，沒有模板保存流程。
- 發布列表已有草稿→發布中→完結流程；草稿按「發布」後直接改狀態，沒有標籤選取。
- 書籍設定、規劃資料及地圖分屬 SwiftData／獨立 store 與 PDF sidecar；完整複製及備份相容性須依本 I 計畫處理。

## 已確認需求（R）

1. 讓側欄「模板」與「論壇」文字左緣一致；保留圖示、點擊區、選取狀態與順序，不要求移動「社群」標題。
2. 草稿按「發布」後先選發布標籤。首輪示範選項為「奇幻」「愛情」「冒險」，允許多選；確認後轉為發布中並保存標籤，在發布列表標示；取消不改狀態或標籤。
3. 模板頁右下角提供圓形框加號。按下後選擇一本既有書，擷取當下完整的書籍設定、大綱與地圖，成功後立即加入「我的模板」。模板快照不包含小說正文。
4. 模板頁頂部提供「我的模板」「搜尋模板」兩個分頁；「搜尋模板」分頁只保留空白頁，不顯示公開內容、不連線目錄或後端。
5. 「我的模板」每張模板卡片下方提供加號；按下後建立一本套用該模板的新書，首頁狀態為「草稿」。
6. 模板資料與新書資料需獨立；套用模板後編輯新書不可回寫模板或來源書。

## 驗收條件

- 側欄模板與論壇文字左緣一致；淺／深外觀、命中範圍與選取狀態正常。
- 草稿按「發布」會呈現三個示範標籤並允許多選；確認後列表顯示所選標籤，取消不變更。
- 從書籍建立模板保留建立當下所有設定、大綱及地圖資料；不帶入正文；成功後立即在「我的模板」可見；取消或失敗不留下半成品，也不修改來源書。
- 模板頁可切換「我的模板」與「搜尋模板」；我的模板可呈現空白狀態及已建立卡片；搜尋模板內容保持空白，不產生網路請求或假資料。
- 模板卡片加號產生新書，新書資料可獨立編輯並列入首頁草稿。

## 非目標

- 不代作者向發布平台上傳／發布作品，也不接入發布平台 API。
- 不複製小說正文；不因建立或套用模板而修改原書。
- 不建立公開模板服務、投稿、帳號、分享或網路搜尋功能。

## UI（U 已確認）

UI 依使用者提供的側欄截圖及操作描述整理；模板頁目前是佔位頁，沒有舊的模板內容畫面可延用。

### 發布流程

```text
草稿列：《書名》                            [發布]
按下發布
┌ 選擇發布標籤 ──────────────────┐
│ [✓ 奇幻]  [ 愛情 ]  [✓ 冒險 ]             │
│                         [取消] [發布]      │
└───────────────────────────────┘

發布中列：《書名》  [奇幻] [冒險]              [完結]
```

### 模板頁

```text
模板
[ 我的模板 ] [ 搜尋模板                              ]

我的模板：
┌ 模板名稱 ─────────────┐   ┌ 模板名稱 ─────────────┐
│ 設定／大綱／地圖摘要   │   │ 設定／大綱／地圖摘要   │
│         [＋ 建立書籍]  │   │         [＋ 建立書籍]  │
└──────────────────────┘   └──────────────────────┘

                                               (＋)  ← 建立模板

搜尋模板：
[ 空白內容 ]
```

- 右下角圓形加號選擇來源書；模板名稱預設沿用來源書名，建立前可編輯。
- 每張「我的模板」卡片下方的加號建立一本草稿；新書建立後再命名。
- 切換「搜尋模板」僅顯示空白內容，不顯示搜尋欄、結果、載入或連線提示。

## I 實作與驗證計畫（已批准）

### 受影響範圍

- `Sailune/ContentView.swift`：固定模板／論壇圖示欄寬，使標題文字對齊；接入模板頁路由；發布按鈕只在標籤確認成功後更新狀態。
- `Sailune/HomeFeatureViews.swift` 與新增模板頁／卡片 View：發布標籤選取 sheet、我的模板／搜尋模板分頁、建立來源書選擇、模板卡片建立書籍、空白與錯誤狀態。
- `Sailune/Book.swift`、`Sailune/SailuneApp.swift`：標籤持久化。建議新增 `Publication Tags.json` sidecar，不改已發布 V5 schema，也不改既有 `Publication Status.json` 編碼；整合書籍刪除清理。
- 新增版本化 `BookTemplateSnapshot`、`BookTemplateStore`、`BookTemplateApplicationCoordinator`：模板保存、跨 store 擷取、UUID remap、新書建立與錯誤回復集中處理；View 不直接操作多個 store。
- `Sailune/V5SettingModels.swift`、`Sailune/BookOutline.swift`、故事規劃／物品副本／能力進度模型：透過明確 snapshot DTO 和現有 Store API 擷取／重建，不修改歷史 schema 快照。
- `Sailune/BookMapPDFStore.swift`：複製地圖版本 PDF；地圖、版本、座標 placement 與 PDF 路徑同步重映射。
- `Sailune/SailuneBackupService.swift`、`SailuneDataLocations`：將本機模板與發布標籤 sidecar 納入備份 manifest、checksum、還原置換及 rollback；舊備份保持可還原。
- 不修改 `SailuneAIBackend`；「搜尋模板」無資料、無 API、無網路請求。
- 完成後更新 `spec-publishing-analytics.md`、`data-model.md`、`backup-and-migration.md`、`consistency-audit.md`、`project-status.md` 及交接。

### 資料範圍與保存策略

1. V5 主 store 完全不升版。模板採版本化本機 payload，涵蓋書籍設定、故事大綱／規劃、世界時間資料、卷節骨架、地圖定義／placements／版本 PDF，以及物品副本與能力進度等書籍關聯資料；排除正文、封面、AI 對話、編輯字數與發布狀態。
2. 保留卷節標題與排序、正文留空，使大綱與時間定位仍有結構可對應。`StoryTag.anchorText`、`OutlineItemAnchor.anchorText` 等含正文引文的錨點不可匯入；依賴正文來源的完成狀態重設為草稿，手動大綱內容與階層保留。
3. 套用模板時為新書及所有內部實體配置新 UUID，以映射表重連跨 store 關聯；不沿用來源 UUID，避免跨書引用及資料互相污染。
4. 新書以草稿建立，不帶來源書發布狀態／標籤。多 store 沒有共同 transaction；Coordinator 先驗證 payload／PDF，再依序保存，失敗時清理本次已建立 UUID 與資產，保留來源書及其他書不變，並回報清理失敗。
5. 舊備份沒有新 sidecar 時，依現有備份政策還原空標籤／空模板庫並保留 rollback 能力。

### 工作拆解

1. 修正側欄圖示欄位並接入模板路由；完成標籤 sidecar 的 backward-compatible 載入／保存、刪書清理及備份接線。
2. 定義 Codable 模板 payload 和版本邊界，為各 store 建立明確 snapshot DTO／ID 映射；從所選來源書建立本機模板。
3. 實作套用流程：驗證 payload、重映射 UUID、保留空白卷節骨架、重建設定／規劃／地圖資料與 PDF，建立草稿；失敗時清理半成品。
4. 實作我的模板列表、來源書選擇、建立模板及卡片加號建立書籍；搜尋模板分頁維持空白。
5. 更新備份以收納標籤與模板 metadata/assets，驗證新舊 archive 還原。
6. 更新產品、資料與備份規格並執行批准範圍內驗證。

### 驗證項目（尚待隔離資料人工驗收）

- 標籤：舊 status JSON 可載入；選擇／取消、多標籤保存重開、恢復連載保留、刪書清理；sidecar 寫入失敗不錯誤切換狀態。
- Snapshot：不同書籍隔離；設定／排序完整；正文、引文錨點、封面、AI 對話、字數與發布狀態不混入；地圖 PDF／版本／placements 完整；無效／未知版本 payload 不產生模板。
- 套用：所有實體產生新 UUID 且關聯有效；正文為空；大綱、設定、地圖可讀可編輯；來源書及其他書不變；任一 store 失敗、地圖 PDF 缺失／損壞不留下半套新書，清理錯誤可見。
- 備份：新封裝含 tags/templates/PDF 並 round-trip；舊封裝無 sidecar 可還原；中途失敗復原舊 sidecar；不破壞六個既有 store schema。
- UI：sidebar 文字對齊；標籤可鍵盤操作及取消；我的模板空／有資料；搜尋模板留白；來源書選取與建模板；模板加號建草稿；淺／深外觀、accessibility 與錯誤狀態。最後用隔離資料做 GUI 驗收，不操作正式作者作品。

### 風險

- 完整模板跨六個 store、地圖 PDF 與正文錨點；現有程式沒有跨書複製功能，UUID remap 與失敗復原是主要風險。
- 正文引文錨點及依賴正文的完成狀態必須按「不複製正文」規則處理，避免意外把原文片段帶入模板。
- 多 store 無共同原子交易，需明確保存順序與失敗清理行為。
- 功能實作與 Debug build 已完成；下方 UI 與持久化行為需用隔離資料人工驗收。

## 2026-09-26 範圍修正

依使用者最新指示，模板只保留設定集、地圖，以及依世界日期定義的時間軸（含時間事件）。卷與節次、正文、章節定位、敘事大綱、故事線／階段／大綱項目與其規劃資料均不轉移。既有模板載入時清除排除欄位；新模板保存前也清除。建立草稿成功後直接進入書籍總覽。此節取代上方較早的卷節骨架與敘事大綱驗收敘述。
