# V9.2am 角色外觀視圖責任分檔

> 狀態：closed（本次純分檔完成；整個 V9 模組責任仍 active）；R approved（使用者要求依凍結清單完成剩餘模組責任）、U not_applicable（純移動來源，畫面與操作不變）、I approved（使用者要求開始完成清單）。

## 工作單元

- 目標：把 `CharacterSectionViews.swift` 中獨立的 `CharacterAppearanceSectionView` 與私有 `AppearanceRow` 搬到具名外觀檔，減少角色多分頁檔的混合責任。
- 完成條件：外觀新增、刪除、類型選擇、描述、場景／用途及時間定位的原有來源語句與資料綁定不變；Debug build 通過；模組清單記錄處置。
- 相關範圍：兩個外觀視圖型別與跨檔共用的空狀態 helper 可見性。
- 非目標：改動外觀列位置、尺寸、顏色、文案、命中或 SwiftData 模型；V9.1am／V9.1af 等 UI 待核定事項不包含在本工作單。

## 風險與驗收

`CharacterSectionEmptyState` 原為檔案私有，外觀分檔後需給同模組存取；其畫面實作不變。編譯後仍須以實際 UI 核對 `AppearanceRow`，不能以編譯代替命中與 Light／Dark 驗收。

## 結果

- `CharacterAppearanceSectionView` 和 `AppearanceRow` 原文搬至 `CharacterAppearanceViews.swift`；原檔只變更空狀態 helper 可見性。
- 主機無簽章 macOS Debug build 通過；外觀 GUI 與資料操作仍依 V9 固定驗收清單進行。
