# V9.1q 完成操作文案統一

> 狀態：closed（17 個既有「完成」按鈕已接入通用文案）
>
> 工作單位：結束目前編輯／管理流程的按鈕共用同一文字資源，保留各流程原本的儲存與關閉順序。

## 現況與完成條件

- 九個 Swift 檔共有 17 個 `Button("完成"...)`，用途是結束目前 sheet、詳情或編輯流程；其中部分按鈕先保存或回報錯誤再關閉，不能把 action 合併為通用 dismiss。
- 新增 `SailuneActionCopy.done` 與 String Catalog 的 `action.done`，繁體中文仍為「完成」。17 個按鈕只替換標題來源；原 closure、style、role、快捷鍵、禁用條件與保存失敗時的早退保持。
- 提示已讀「好」、操作確認「確認」與流程結束「完成」維持三種語意 key。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求相同操作的敘述文字由統一程式碼提供。 |
| U | not_applicable | 字面值、位置與互動不變。 |
| I | approved | 增加一個通用文案 key，替換 17 個現有按鈕標題。 |
