# V9.1v 欄位前置條件提示圖標統一

> 狀態：closed（4 個前置條件提示已引用同一語意 key）
>
> 工作單位：集中角色歷史與設定編輯中「缺少必填值／前置資料」提示的既有圖標。

## 目標與範圍

- 將物品名稱、能力等級名稱、歷史描述及故事線前置條件的四個提示統一使用 `SailuneSymbol.requirementNotice`。
- 保留原 `exclamationmark.circle`、各自繁體中文說明、驗證時機、位置與流程。
- 不合併錯誤、警告或空狀態的其他圖標；只處理以上四個已確認的前置條件提示。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者要求相同功能圖標集中定義；四處均向使用者說明繼續操作所需的欄位或資料前置條件。 |
| U | not_applicable | 圖形、文案、顏色、位置與顯示時機不變。 |
| I | approved | 屬 V9 共用圖標資源採用，限四處既有提示。 |

## 驗收與驗證

- `SailuneSymbol.requirementNotice` 唯一提供原 `exclamationmark.circle`。
- 四個既有 Label 均引用該 key；提示內容與顯示條件不變。
- `git diff --check` 與無簽章 macOS Debug build 通過；無程式測試或 GUI 行為改動。
