# 帆夢（Sailune）專案現況

> 最後核對：2026-09-22；依目前程式碼、測試與 Xcode 設定整理。

## 專案定位

帆夢是一套 macOS 長篇敘事創作工具，核心不是單純保存設定，而是把正文、人物、關係、物品、能力、敘事大綱與世界時間放在同一個寫作工作區中，降低作者在大型群像故事裡回想與查找資訊的負擔。

目前最成熟的價值是：作者可直接寫作，並逐步把正文中的角色與大綱來源連回設定資料；需要時再打開設定集或寬版規劃畫面，不強迫先填完整世界觀。

## 可宣傳與不可宣傳的邊界

現在可以開始問題訪談、開發日誌、概念頁與封閉名單預宣傳。可如實主打「把正文、大綱、人物關係與世界時間連起來」及「從正文回到設定、從大綱跳回正文」。

目前不應宣稱「自動找出所有未回收伏筆」。實作已有正式的「伏筆」標籤、標籤清單與正文定位，但沒有尚未回收／已回收狀態、未回收篩選、回收位置或完成流程。這是經使用者訪談確認的重要下一個產品方向。

也不宜把現況包裝成可公開下載的穩定版：雖然匯出、備份／還原與跨 store 清理已實作並有自動測試，正式簽章、封裝、真實 UI 操作與故障注入驗收仍未完成。
