# V11.5 本機資料空間

R／U／I 已於 2026-09-29 由使用者分別確認需求、U、I。產品限制為一個未登入空間加最多兩個帳號空間；同時使用一個工作區，各視窗統一切換。

## 使用行為

- 未登入也能寫作。帳號工作區按 Supabase 環境與 Auth user UUID 識別，Email／筆名只供顯示；重登同一身分不占新位置。
- 右下既有帳號選單的「切換帳號」開管理面板，列未登入與兩個帳號位置。空位置提供新增帳號，满額須先移除一個。帳號可快速開本機資料；網站仍只有一個 Session，發布須核對目前工作區 UUID／環境與 Session 一致。
- 切換前完成各視窗輸入與保存；保存或目標載入失敗保留原工作區。發布仍進行或遠端成功但本機保存未完成時不可切換／刪除。AI 任務停止，舊回呼不得寫入新工作區。
- 主動登出成功後回未登入；Session 到期或離線不自動搬移本機資料。重開恢復上次成功選定的可用工作區。
- 帳號與未登入作品不自動合併。舊共用資料複製至 Guest，保留原始來源、書籍 UUID 與遷移安全備份。

## 保存範圍

每個工作區獨立六個 SQLite store、作者資料、封面、地圖、AI 對話、模板、論壇、寫作統計、發布狀態／標籤、工作區偏好、pending restore 及 App 管理安全備份。主 schema V5、settings V13、planning V7 不變；工作區登錄為版本 1 JSON，不含 token。

Auth Session 保留既有鑰匙圈 service／account key／失敗封鎖政策，不存工作區 JSON／偏好或備份。資料空間隔離不代表加密，不提供同一 macOS 使用者的檔案保密保證。

## 刪除

名稱為「刪除此裝置上的帳號與資料」。確認列目標帳號與不可復原範圍，提供先備份、取消與刪除；未登入空間不提供本次帳號刪除入口。刪目前帳號先準備 Guest；其他帳號刪除不更換目前空間。

清理先保存紀錄、停止持有目標的 store／任務，再刪受管理目錄、偏好與對應 Session。失敗保留清理中登錄與重試入口；清理中的空間不可開啟，名額不釋出。全部完成才移除帳號登錄；刪除開始後不承諾中途取消／復原。自訂確認外部空白在開始刪除前可取消且不穿透。

不刪除 Supabase／拾頁會員、網站已發布作品，或使用者自行匯出的外部備份。刪除是移除本機資料，不能宣稱永久抹除磁碟位元。

## 備份與驗收

新備份 manifest 記來源工作區，只可直接還原至相同工作區；無來源的舊備份限定 Guest。跨帳號匯入與雲端同步不在本輪範圍。

驗收：三空間切換與重開隔離、相同作品 UUID 資產／快取隔離、兩帳號名額、保存／載入／登錄失敗保護、遷移冪等與 UUID 保留、局部清理中斷可重試、Guest／其他帳號不受刪除影響、發布身分不匹配拒絕、備份来源限制，以及實際滑鼠／keyboard／多視窗／空白取消 GUI。


## 未登入資料移入空帳號（R／U／I approved，2026-09-29）

- 資料空間面板提供「移入帳號」，只可選已加入、可讀、無使用者資料的目的地。確認列目的帳號與來源清空／安全備份說明；確認前取消或點空白不搬移。
- 來源六 store／UUID／引用、封面、地圖、對話、模板、作者寫作資料、統計、論壇、草稿發布／標籤及偏好整體移入，成功切换目的帳號，Guest 重置可重新寫作。目的帳號 UUID／Email／Session 不改；網站沒有自動發布或所有權轉移。
- 空間判定涵蓋全部模型／資產／sidecar／偏好；一個無簡介／頭像、筆名為空或「我的筆名」的初始作者與已知初始偏好允許，不能僅以作品數為零判空。未知資料／檔案、損毀、符號連結、清理中或待還原拒絕。
- Guest 非草稿發布紀錄拒絕：目前 sidecar 沒有遠端作者 UUID，不能把本機搬移視為網站所有權轉移。逐本／合併／帳號間搬移不在本版。
- 專用移入交易：保存目前工作、建立兩端備份、SQLite snapshot 與資產副本、欄位／引用與 SHA256 驗證、卸載視窗舊 bundle、置換／commit、Guest 重置。Core Data 的 Z_OPT 為儲存修訂號，不屬資料內容比對；其他模型欄位與實體主鍵仍驗證。
- transfer.json 記交易 UUID／目的帳號／階段與驗證摘要；Transfer Recovery/<UUID> 保存安全備份及原始目錄。commit 前重開回復目的地並保留 Guest，commit 後完成 Guest 重置；未知或復原錯誤保留資料／journal 並提供重試。保留的 Guest 備份仍屬 Guest，不放寬一般跨空間還原。
- 移入期間禁止編輯／切換／刪除及重複操作；卸載期間顯示進度。完整成功後顯示「移入完成」，失敗不宣稱成功。舊復原／pending restore 不作工作內容搬往目的帳號。

## 暫時移入例外已關閉（2026-09-29）

使用者要求關閉測試許可，Debug／Release 均恢復非草稿 Guest 來源拒絕；移除暫時旗標／放行注入，不回復已移入內容或安全備份。

## 未登入禁止發布（2026-09-29）

Guest 工作區不能發布，即使裝置記住其他帳號的網站 Session。已加入本機帳號仍需相符的有效 user UUID／環境；缺失／失效或不匹配時停用草稿、連載、完結的「傳送至拾頁」。仍可瀏覽发布列表／數據與本機寫作。

預覽準備與發布服務 action 均經具名 requirePublicationAccount 檢查；Guest／缺身分在取得憑證或網路傳送前拒絕。Auth credentials 的 expectedUserID 必填，實際 Session 必須一致。僅停用入口不能取代服務檢查。
