# V12.1 拾頁端共享模板／論壇交接

> 2026-10-03；帆夢工作單 R／U／I 已批准。這是給拾頁端制定與實作正本契約的需求交接，並非已發布的 API 規格。拾頁 repo 依自身 AGENTS.md 與 `docs/auth-contract.md` 批准流程工作；本檔不授權帆夢直接改 Supabase。

## 已批准的產品行為

- 帆夢與拾頁共用 Supabase Auth。帆夢全 App 除本機創作外需登入；Guest 仍能建立書籍、寫正文、編輯角色／設定。這與目前拾頁 `docs/auth-contract.md` §4「所有本機功能照常運作」不一致，請由拾頁端修訂正本、升版後供帆夢整份同步複本。
- 作者於帆夢「我的模板」手動確認並上傳後，所有**已登入**使用者可在「搜尋模板」看到與套用。建立本機模板本身不公開；取消公開不刪本機模板。公開內容包含角色、設定、地圖、時間軸與可能內嵌的 PDF 地圖資產；不包含正文。`BookTemplateDocument.currentVersion == 1`，帆夢目前先移除舊版寫作結構再保存本機 JSON，套用時重新配置 UUID。
- 論壇保留五分類：`announcements`、`writing`、`works`、`sailune`、`suggestions`。登入者手寫標題／內文並發表至共用論壇；一般分類僅本人可編輯／刪除。`announcements` 所有登入者可讀，只有 `is_admin()` 能新增／編輯／刪除。
- 現有每工作區 `Forum Posts.json` 是舊本機文章，沒有遠端作者身分；不得自動上傳、混入共用列表或在更新時刪除。備份仍管理本機檔案。

## 待拾頁端凍結的遠端契約

1. 提供已登入的模板列表／搜尋／單筆讀取、冪等發表、本人取消公開；返回公開 ID、作者顯示名、格式版本、摘要、建立／更新時間與公開狀態。列表不得回傳私有模板，取消公開後一般讀取也要拒絕。上傳／下載負載與 PDF 資產需伺服器限制大小、數量與格式，並驗證模板版本及不含寫作結構；不能依賴 App 的確認畫面當安全檢查。
2. 提供已登入的論壇分類列表／單筆讀取、冪等發文、本人更新／刪除與管理員公告操作；返回文章 ID、分類、作者 ID／顯示名、標題、內文與時間。作者 ID 取自 JWT，管理員以資料庫 `is_admin()` 判定，不接受 App 自報角色。
3. 訂出穩定的錯誤分類與版本化資料格式，至少區分未登入／Session 失效、權限不足、格式或容量錯誤、頻率限制、衝突／重複、已取消公開／不存在及暫時服務失敗。重試使用客戶端操作 UUID，避免重複模板或文章。
4. 明確說明 App 使用的 URL／RPC 名稱、請求與回應 JSON、頁面大小與游標、排序、搜尋語意、容量上限、管理員權限查詢、撤回和刪除語意，以及遷移與部署順序。帆夢在契約標為「已實作」前不假設端點存在。

## 服務端驗收

- migration 新建與重跑、RLS／RPC 匿名、作者 A、作者 B、管理員矩陣；非管理員直接呼叫公告寫入也被拒。
- A 發表後 B 可讀並套用，B 無法改／刪 A 內容；取消公開後 B 的列表與舊 ID 讀取均不可得；本機模板與文章不受遠端刪改影響。
- 無效版本、含正文／寫作結構、過大 PDF、重複操作 ID、連續提交及網路中斷重試均有確定結果，不產生孤立公開資產或重複貼文。
- 完成 migration、部署與兩個真實帳號跨安裝測試時各自記錄；測試替身或提交不可當作正式聯網成功。

## 帆夢端已進度

- 訪客側欄「尋找／發布／模板／論壇／成就／帳號」已接現有工作區＋Session 匹配檢查並顯示登入提示；首頁書櫃、建立／匯入書籍及創作入口維持可用。隔離 App AX 已見論壇登入提示、登入畫面及返回首頁建立書籍入口。
- 遠端模板／論壇 client 尚未接線；待上列契約凍結後實作與端對端驗收，不能以目前本機 Store 充當共享服務。
