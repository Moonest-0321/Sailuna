## 核心流程

- [ ] 建立書籍、卷、節；輸入中文正文、自動儲存並重開。
- [ ] 幕標題、查找替換、跨節導覽與字數正確。
- [ ] 建立／連結角色，測試真名、別名同步與未連結候選。
- [ ] 建立設定、物品副本、能力、關係與歷史並重開。
- [ ] 建立故事背景、四類故事線、兩個主線階段、正文／手動大綱，測試跳回正文。
- [ ] 建立紀元、節點與事件，從大綱加入世界時間，測試主副軸與刪除。
- [ ] 驗證伏筆／修改失效後的共同 Undo／Redo。
- [ ] 依目前編輯器支援範圍驗證右鍵選單與 Apple 寫作工具狀態；使用者可見流程以最新規格為準。
- [ ] TXT／EPUB 可由使用者選擇目的地，輸出順序與特殊字元正確。
