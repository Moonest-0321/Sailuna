# V9.1p 提示確認文案統一

> 狀態：closed（32 個既有「好」按鈕已接入通用文案）
>
> 工作單位：相同的訊息確認動作統一取得文字資源，保留各畫面原本的關閉動作和鍵盤行為。

## 現況與完成條件

- 15 個功能 Swift 檔共有 32 個 `Button("好"...)`，用於確認提示／錯誤或訊息視窗；部分按鈕帶 `.cancel` role，一處帶預設快捷鍵。
- 新增 `SailuneActionCopy.acknowledge` 與 String Catalog 的 `action.acknowledge`，繁體中文仍為「好」。32 個按鈕只替換標題來源，原 action closure、role、快捷鍵、位置和 alert／sheet 文案保持。
- 「確認」與「好」用途不同：前者可用於執行操作，後者只表示已讀提示。`完成` 主要關閉工作流程，也未混入本批。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求相同功能使用相同敘述文字並由統一程式碼調用。 |
| U | not_applicable | 顯示字、按鈕位置、role、action 與快捷鍵均保持原樣。 |
| I | approved | 增加一個通用文案 key，替換來源碼中 32 處相同的字面值。 |

## 驗證與限制

- 2026-09-24：String Catalog JSON 語法檢查、`git diff --check` 與主機無簽章 macOS Debug build 通過；來源碼已無 `Button("好"...)`。未執行程式測試、GUI 或 VoiceOver 驗收。
- 不把訊息標題、領域刪除確認及「完成」按鈕視為相同操作；後續需逐語意盤點 tooltip 與 accessibility label。
