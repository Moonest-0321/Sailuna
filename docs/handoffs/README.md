# 交接文件導覽

- [current.md](current.md)：目前主要工作交接，記錄工作樹、進度、驗證、阻礙及唯一下一步；不取代目前工作單。
- [template.md](template.md)：新交接檢查點範本。
- [v9-current.md](v9-current.md)：V9 工程規則化專題狀態；即使目前主要工作切換至 V10，V9 的暫停狀態與續接點仍由此保存。
- [v9-pause-checkpoint-2026-09-25.md](v9-pause-checkpoint-2026-09-25.md)：V9 暫停時的詳細固定清單、決策及續接資訊。

一般工作完成後，長期產品規則分流至規格／ADR／測試文件；`current.md` 不作為歷史事件資料庫。專題交接只有在該專題仍有明確後續時保留 active／paused。
