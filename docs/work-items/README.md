## 工作單與交接的分工

- 工作單說明目標、範圍、非目標、批准及完成條件。
- 交接說明工作樹邊界、實際進度、驗證結果、阻礙與唯一下一步。
- 目前工作單與交接不可互相取代；操作流程見 [development-workflow.md](../development-workflow.md)。
