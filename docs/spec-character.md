# 角色設定功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-09-21

## 1. 功能目的

讓作者集中管理角色身份、背景、性格、外觀、能力、物品、關係與事件，並能回到正文確認角色實際出現的位置。角色資料是選配的設定層，不應成為單純寫作的必要前置作業。

## 2. 使用流程

1. 在編輯工作區開啟右側「設定集」。
2. 進入角色頁籤，搜尋或新增角色。
3. 編輯角色基本資料與各個可收合區塊。
4. 視需要加入別名、組織、能力、外觀、心理、物品、關係與事件。
5. 從「正文引用」查看角色出現的節，或從正文中的角色名稱跳回角色詳情。

V6.3 的角色詳情保留正文引用的原位置與行為；摘要固定顯示，其餘設定區以單欄圖示列呈現，並常駐顯示各自最新一筆預覽。角色時間定位提供兩個按鈕與彈窗：敘事版本選卷／節，時間序版本選紀元／年／月／日。

## 3. 目前已確認行為

### 3.1 角色基本資料

- 每個角色屬於一本書，具有真名、性別、出生資料、出身、來歷、小記、性格與原則欄位。
- 真名是主要識別名稱；建立角色時會先以「新角色」作為預設名稱。
- 角色列表支援搜尋真名、小記與別名。
- 關係網與關係列表共用的角色搜尋欄支援搜尋關係對象的本名與別名；只輸入空白時不套用名稱篩選。
- 可將角色置頂，並保留手動排序。
- 角色摘要區固定直接顯示，不提供收合狀態。
- 摘要未手動指定時，別名、能力、心理與關係自動取可用的最新記錄；有內容時直接顯示名稱，不加「自動」前綴。能力包含正式角色能力連接，關係包含角色作為任一端的記錄。
- 基本資訊、別名、能力、外觀、心理、物品、關係與事件是單欄圖示列；收合或展開時都顯示最新一筆預覽，點擊整列在原頁展開既有編輯內容。
- 能力預覽顯示最新能力名稱與目前等級；未選等級時顯示「未設定」。

### 3.2 別名與正文引用

- 一個角色可以有多個別名，每個別名可附註記。
- 正文可透過真名或別名建立角色連結。
- 角色真名修改後，系統會掃描正文並提供未連結舊名稱的選擇性替換。
- 刪除角色時，正文文字保留，但角色連結解除。

### 3.3 外觀與心理

- 外觀資料目前分為「服裝」與「身體特徵」。
- 每筆外觀可記錄描述、用途與備註。
- 心理資料目前分為「性格」、「價值觀」與「動機」。
- 外觀與心理資料可各自建立多筆，並可指定時間定位。
- 角色相關時間定位不直接鋪在內容列上；「敘事版本」彈窗先選卷、再選該卷的節，「時間序版本」彈窗選紀元並手填年／月／日。既有定位值保留，編輯共用 Node 時以複製方式隔離其他紀錄。

### 3.4 組織與身分

- 角色可加入既有組織，也可從角色頁面建立新組織。
- 加入關係可記錄加入原因與備註。
- 每個組織身分可建立多筆身分歷史，並指定時間定位。
- 角色詳情以獨立圖示區塊提供「所屬勢力」：同一角色可加入多個本書勢力，每筆只顯示勢力名稱與單一職稱；不放在基本資訊內。
- 角色頁可新增、切換或解除所屬勢力；同一角色不可重複加入同一勢力。解除只刪除成員關係，不刪除勢力。
- V6.3 的角色所屬勢力簡化介面不呈現現任／前任、加入／離開時間或多職務歷史；進階資料仍由勢力詳情管理。

### 3.5 能力

- 角色可連接既有能力。
- 角色的能力資料包含目前階段、階段描述與摘要。
- 可建立能力階段歷史，並指定時間定位。

### 3.6 物品

- 角色可連接既有物品，並記錄持有數量。
- 角色物品可建立歷史紀錄與時間定位。
- 物品與副本的共用設定由物品系統管理；角色頁面負責連接與持有關係。

### 3.7 關係與事件

- 可建立角色對角色的一般關係，也可建立血緣關係。
- 關係可記錄類型、備註與關係歷史。
- 角色事件區彙整該角色的能力、外觀、心理、物品、關係及直接關聯事件時間序；只有已賦予時間序定位的紀錄才顯示，並依日期與卷／節排序。
- 直接關聯事件可在角色頁面新增、編輯與刪除；其他來源在事件彙整中只讀，仍由各自設定區編輯。
- 提供關係網檢視入口。

### 3.8 正文引用檢視

- 角色詳情可顯示其在正文中出現的節。
- 可從引用項目跳轉至對應節。
- 系統會區分已連結引用與可能提及但尚未連結的文字。

## 4. 刪除與資料安全

- 刪除角色前會顯示確認訊息。
- 刪除會移除角色設定、關係與事件關聯；正文內容本身保留。
- 若刪除失敗，會回復此次資料變更並顯示錯誤訊息。

## 5. 待確認的產品決策

- 角色真名是否必須唯一，以及同名角色的處理方式。
- 「性格／原則」與「心理資料」之間的分工，是否需要合併或明確區隔。
- 出生資料中年、月、日、季節與出身欄位的正式語意。
- 一般關係與血緣關係是否有固定類型清單。
- 角色歷史的時間定位是否必須填寫。
- 刪除角色後，是否需要提供復原或解除連結的專用流程。

## 6. 驗收條件（目前版本）

- 能在指定書籍中新增、搜尋、編輯與刪除角色。
- 能建立別名，並由正文真名或別名跳轉至角色。
- 能查看角色的正文引用並跳回對應節。
- 正文引用保持在角色名稱／定位下方的原位置；摘要不收合，八個圖示列顯示各自最新預覽並可在原頁展開。
- 能力預覽包含目前等級；事件列與事件展開內容反映角色全部時間序。
- 角色相關時間定位顯示「敘事版本」與「時間序版本」兩個按鈕；兩者各自開啟只包含指定欄位的彈窗。
- 能建立至少一筆外觀、心理、組織身分、能力、物品與關係資料。
- 能在角色基本資訊加入多個不重複的所屬勢力，編輯各自職稱並解除關係。
- 能為支援歷史的資料建立時間定位。
- 刪除角色後正文文字仍存在，且不再保留失效角色連結。
