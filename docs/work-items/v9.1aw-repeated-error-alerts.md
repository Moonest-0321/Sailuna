# V9.1aw 重複錯誤提示外殼

> 狀態：active；R approved（使用者要求相同重複操作共用）、U not_applicable（沿用原生 alert 的標題、文字、按鈕及角色）、I approved（使用者要求依固定清單完成剩餘項目）。

## 工作單元

- 目標：將地圖兩處「無法完成操作」、大綱三處「大綱無法儲存」以及故事背景一處相同的錯誤提示結構接入共用 `View` modifier。
- 完成條件：每個 alert 原標題、`未知錯誤` fallback、共用「好」按鈕、地圖 `.cancel` role、錯誤 Binding 清除時機保持一致；六個固定 dialog ID 更新處置；Debug build 與程式測試通過。
- 非目標：改變儲存、刪除、錯誤結果、提示位置或其他 UI。
- 風險：原生 SwiftUI alert overload 與 Binding 清除時機；需以程式測試及實際錯誤畫面驗收。

## 接線結果

六處固定 ID V9-0937、0963、1038、1088、1110、1159 已接入共用 modifier；原標題、按鈕 role 與 Binding 行為保留，主機無簽章 Debug build 通過。故障注入及實際錯誤畫面未驗收，工作單維持 active。
