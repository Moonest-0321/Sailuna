# V7 地圖工作區規格

> 狀態：R／U／I 已批准；V7.4 跨層級跳轉實作驗證中。日期：2026-09-23。

## 目的與範圍

每本書在編輯器的地圖模式提供多張固定 4:3 地圖。作者可以匯出純白或無文字網格 PDF，在外部完成地圖後匯入 PDF、PNG 或 JPEG；畫面固定疊加左下角原點、X 向右、Y 向上的 `4000 × 3000` 平面座標，並可建立城市等地點標記。

不提供行政父子階層、透明版本疊加、路徑、距離／旅行時間、區域邊界、勢力控制、多時代地圖或正文／事件自動連結。

## 地圖分類與版本

- 每張具體地圖有一個平面層級：總體、國家、省份、城市或特寫；層級只用於篩選，不保存總體→國家→省份等父子關係。
- 同一本書、同一層級可建立多張作者命名的具體地圖；同層名稱不可重複，跨層可同名。
- 每張具體地圖擁有自己的 placement。相同 Place 可以出現在多張地圖，且各自保存不同 X／Y。
- 總體、國家與省份可建立多個替代背景版本，例如行政區劃、地形、資源位置；一次只顯示一個。城市與特寫使用單一背景，UI 不顯示版本管理。
- 同一具體地圖的版本共用 placement；切換或刪除版本不會移動、刪除標記或 Place。
- 上方工具列提供匯出／匯入，層級、具體地圖與管理地圖依內容寬度組成緊鄰的靠右控制群，座標入口以圖釘置於其右側。管理地圖固定只顯示圖示。縮放控制與條件式圖層切換位於畫布外固定底列：縮放靠左、圖層控制靠右；符合視窗使用等號。深色底列不隨地圖縮放或平移，確保控制持續可見。空白預設地圖使用中深灰。管理地圖與管理圖層統一使用三層正方形圖示。
- 刪除具體地圖會刪除其版本、背景與 placement，但保留設定集 Place。刪除 Place 則清除它在所有地圖上的 placement。

## PDF 行為

- 匯出模板皆為單頁 4:3 PDF，頁面尺寸 `1200 × 900 pt`；純白模板沒有其他內容，網格模板為 40×30 細格、每五格加深，不包含點位或座標資料。
- 匯入接受可讀取的單頁 PDF、PNG、JPEG 與 JPG。多頁 PDF、損壞檔案、無法解碼的圖片或無效尺寸會顯示錯誤，既有背景不變。
- 非 4:3 內容等比例置中縮放至固定白色 4:3 畫布；不足方向平均補白，不裁切、不拉伸。透明 PNG 的透明區域合成白色。
- 圖片匯入後正規化為單頁 `1200 × 900 pt` PDF 保存；不保留另一份圖片原檔。
- 正規化後的完整 4:3 畫布對應 `4000 × 3000`，因此白邊也屬於座標平面。
- 每個地圖版本保存一份 PDF；再次匯入以原子寫入替換目前版本背景，不修改、重算或刪除任何 placement。

## 座標與點位

- 畫布左下角是 `(0,0)`，右上角是 `(4000,3000)`；SwiftUI 畫面座標的 Y 軸在轉換時反向。
- PDF、座標軸、刻度與點位共用同一個固定 Fit 尺寸的 4:3 viewport；初始為 100%，可在 `50%...400%` 間縮放並於放大後平移。縮放的是 viewport 內的 content rect，超出部分裁切，外側工作區不會變成地圖；視窗轉換不改變世界座標。
- 工具列提供 25% 級距的縮小／放大、目前倍率與「符合視窗」；觸控板縮放以手勢錨點為中心，拖曳超過門檻才平移。倍率大於 100% 時，觸控板／滾輪可依二維滾動量上下左右平移；一般滑鼠可用 Shift＋垂直滾輪水平平移。
- V12 以 `MapPlacement` 的 map ID、Place ID 與 X／Y 表示標記；`Place.coordinateX/Y` 只保留作 V11 單圖遷移來源，新操作不再寫入。
- 點擊空白位置先開啟最小編輯表單；輸入名稱、類型與 X／Y 整數座標並儲存後才建立 `Place`。點擊位置會預填座標，取消不留下資料。
- 地圖工具列另提供「輸入座標」，不必先點擊畫布即可開啟同一新增表單；此入口的 X／Y 初始為空白。
- X 合法範圍是 `0...4000`，Y 合法範圍是 `0...3000`；空白、非整數或超界時停用儲存並顯示錯誤，不自動截斷到邊界。
- 點擊既有標記的圓點或可見名稱可修改名稱、類型與座標，也可經確認後永久刪除整筆 `Place`；刪除後會同時從地圖與設定集消失，且無法復原。既有標記表單可直接開啟右側設定集的同一 Place 詳情，未儲存的表單改動不會隨跳轉寫入。
- 標記以座標為圓心顯示固定 6 pt 實心點，命中區為 24 pt；hover、選取或倍率達 `150%` 時顯示名稱，選取另加 12 pt 細外環。名稱浮標固定使用黑字與白底，確保深色外觀仍可讀；類型不常駐於畫布。
- 圓點與可見名稱形成同一 hover、點擊與拖曳區；表單關閉後選取外環即清除。既有標記拖曳超過 8 pt 時顯示即時整數座標，放開直接保存；超出畫布時貼齊最近邊界。空白畫布拖曳仍用於平移 viewport。
- 目前不提供地點連接；留待後續工作單。

## 地點進入下一層級地圖（V7.4）

- 總體、國家、省份地圖上的既有標記在編輯表單顯示「前往城市地圖」；城市地圖顯示「前往特寫地圖」；特寫不顯示此按鈕。新標記需先儲存。
- 第一次按下時，以已儲存的地點名稱在同書目標層級尋找同名地圖，名稱依現有規則 trim 並不分大小寫比較。找到時直接綁定並進入，不修改既有圖內容；找不到時建立同名空白地圖及預設版本，再綁定並進入。
- 綁定保存在來源 `MapPlacement.targetMapID`，屬於來源地圖上的該地點；後續以地圖 UUID 跳轉，即使名稱變更也不重新配對。不同來源地圖上的同一 Place 可以有各自的目標。
- 刪除目標地圖會清除所有指向它的綁定，來源 Place 與 placement 保留；下次按鈕依當時的 Place 名稱重新配對或建立。刪來源 Place 或地圖時依原規則移除來源 placement。
- 跳轉只切換目前層級、具體地圖及其 session viewport；不自動把來源 Place 加到目標地圖。表單未儲存的編輯不隨跳轉寫入。名稱空白或保存失敗時不建立目標圖，維持原地圖並顯示錯誤。

## 工作模式

- 編輯、大綱與地圖是同層互斥模式，以原有書本、大綱與地圖圖示組成的三段控制直接切換，不建立返回層級；文字名稱保留在 accessibility label 與 tooltip。
- 切換前提交正文待存內容；從大綱指定內容跳轉時直接進入編輯模式。
- 每張具體地圖的倍率與中心在目前書籍工作區存活期間分別保留；切換版本維持同一 viewport，重新開啟書籍時回到 Fit。右側設定集獨立開合，模式切換不強制改變其狀態。

## 資產、備份與刪除

- 地圖 PDF 存於 `Sailune/Maps/<bookID>/<mapID>/<versionID>.pdf`，不寫入 SwiftData；分類、版本與 placement 存於 settings V12。
- 完整備份遞迴包含六個 SQLite snapshot、`covers/` PNG 與 `maps/` PDF 的安全相對路徑。舊備份沒有 `maps/` 時仍可還原，並清除目前地圖資產。
- settings V10／V11 備份可在 V12 應用還原，下一次啟動依 migration chain 升級。首次進入地圖時建立「總體／總體地圖」，把合法舊座標轉成 placement，並將舊 `<bookID>.pdf` 驗證後原子搬入巢狀版本路徑；流程可安全重試。
- 刪除書籍會透過跨 store coordinator 清理該書的 settings 資料、封面與地圖 PDF；地圖資產清理失敗會列入可重試的 deferred cleanup。

## 驗收條件

- 可由地圖工作區匯出純白／網格 PDF，兩者皆為可開啟的單頁 4:3。
- 可匯入 4:3 或其他比例的單頁 PDF、PNG 與 JPEG／JPG；其他比例完整保留並補白，透明圖片以白色合成。
- 地圖上可辨識四角範圍與座標方向，深色／淺色 App 外觀都可閱讀。
- 點擊位置可新增名稱／類型標記，也可直接輸入合法整數座標；關閉重開後仍在相同座標。
- 可不點畫布直接從工具列輸入 X／Y 建立標記；空白或無效座標不可儲存。
- 既有標記的刪除需先確認；取消不改資料，確認後整筆 Place 刪除，其他地點與背景保留。
- 替換或切換版本前後，既有標記數量與數值座標完全相同；切換具體地圖則顯示該圖自己的 placement。
- 編輯、大綱與地圖可直接互切，且只有一個主模式；設定集顯示狀態不被模式切換改寫。
- 地圖可在 `50%...400%` 間縮放、回到 Fit 並於放大後平移；任何 viewport 下座標 round-trip 不漂移。
- 標記是固定 6 pt 精確小點；hover／選取與 `150%` 以上的名稱顯示符合語意縮放規則。
- 圓點與可見名稱都能開啟同一標記；關閉表單不殘留任意選取名稱，並可從表單跳至同一 Place 設定。
- 拖曳標記只更新目前地圖的 placement，與空白地圖平移不衝突；超界放開固定在最近邊界。
- 既有標記可由總體／國家／省份前往同名城市地圖，由城市前往同名特寫地圖；已有目標圖保留內容，沒有時建立空白圖。後續跳轉保留改名後的綁定，刪除目標後可重新配對。
- V10／V11 Place 遷移後原欄位與 UUID 保留；合法 V11 座標只回填一次，地圖資產可隨備份還原並隨書籍刪除。
