# V9.2i AI 勢力設定讀取錯誤傳遞

> 狀態：closed（勢力分析附件的設定 store 查詢錯誤已傳遞）
>
> 工作單位：讓 AI 勢力設定快照讀取設定 store 時，查詢失敗停止附件送出，而非把失敗視為空列表。

## 目標與完成條件

- `V5SettingsStore` 提供僅供既有分析附件使用的 throwing 模型讀取入口，維持 revision 觀察；既有各畫面 nonthrowing 列表 API 不變。
- `SailuneAIAnalysisContextBuilder` 的勢力目標查找與 `powerSnapshot` 各已使用的設定 store 查詢，改由此入口讀取並保留原 book／power／member 過濾、排序與附件格式。
- 任一查詢失敗由既有 `settingAnalysisAttachment`、`EditorWorkspaceView` catch 回報，不送出不完整附件；真正無資料時仍維持空資料語意。
- 不修改 SwiftData schema、設定資料、AI prompt、控制項或其他功能畫面查詢行為。

## 驗證與限制

- 2026-09-24：勢力目標查找與快照中的勢力、層級、成員、職務、隸屬、關係、世界條目、資產、優勢、沿革及承接讀取均改走 `fetchForAnalysis`；原 book／power／member 過濾與已定義排序保留。成員為空時不查職務。
- `git diff --check` 與主機無簽章 Debug build 通過；未新增或執行程式測試、故障注入與 GUI 驗收。
- 此入口只覆蓋設定分析附件；設定選取器或其他畫面仍可能使用 nonthrowing 列表 API，需獨立稽核。
