# V9.1m 一般單行表單欄位試行

> 狀態：closed（六個一般單行欄位已接入）
>
> 工作單位：讓六個僅使用原生圓角邊框樣式的獨立文字欄位共用一個基礎元件。

## 目標與完成條件

- `SharedUI` 建立 `SailuneFormTextField`，接收原有 `LocalizedStringKey` title 與 `Binding<String>`，內部仍為 `TextField(...).textFieldStyle(.roundedBorder)`，保留原文字面值使用的本地化 initializer。
- V5 設定頁的勢力名稱、關係說明、地點名稱／其他名稱／類型、世界條目其他名稱六處接入；原綁定、文字、資料保存時機與周圍 layout 不變。
- 暫不處理套在容器上的 `.textFieldStyle`、名稱欄 focus、搜尋、數值／日期、縱向多行 TextField、具驗證或提交行為的欄位。
- 通過六處靜態核對、`git diff --check` 與主機 Debug build；CJK、focus 與 VoiceOver 仍須後續 GUI 驗收。
