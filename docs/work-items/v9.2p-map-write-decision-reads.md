# V9.2p 地圖寫入決策查詢

> 狀態：closed（既有 throwing 寫入入口的地圖／版本查詢已傳遞錯誤）
>
> 工作單位：建立、改名地圖／版本與標記跳轉時，必要查詢失敗要在寫入前停止，交由現有錯誤出口呈現。

## 現況、範圍與完成條件

- `createMap`、`createVersion` 原先以 nonthrowing 列表取得排序；同名驗證亦使用同一列表。讀取失敗時，空陣列可讓重名資料通過驗證，或把新資料排序為第一筆。
- `destinationMap` 原先用空陣列判斷沒有已綁定或同名目的地，讀取失敗可能建立另一張地圖並改寫來源綁定。
- 本批為上述決策新增私有可拋錯查詢，保留原書籍／層級／地圖過濾和排序。建立、改名、跳轉在讀取失敗時沿既有 `do/catch` 顯示錯誤；正常空清單仍按原規則建立。
- 不改 SwiftData schema、地圖分類、名稱比對、UI 位置、一般列表顯示、首次初始化與標記來源查詢。`ensureDefaultMap`、畫面列表及標記跳轉前的來源 `places`／`placements` 仍屬 V9.2c 待決範圍。

## 驗證與限制

- 2026-09-24：`createMap`、`renameMap`、`createVersion`、`renameVersion`、`destinationMap` 的必要地圖／版本查詢已改走可拋錯路徑；所有新查詢在寫入前完成。
- `git diff --check` 與主機無簽章 macOS Debug build 通過。未執行程式測試、故障注入、實際地圖操作或 GUI 驗收；編譯不能證明失敗分支的畫面結果。
- 三個供畫面讀取的 nonthrowing 列表 API 保留；本批不能視為 V9.2c 全部完成。
