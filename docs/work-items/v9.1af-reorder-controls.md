# V9.1af 上下移動控制語意統一

> 狀態：active（R approved；U pending；I pending）
>
> 工作單位：讓相同的清單上移／下移操作使用同一組圖標與一致的操作名稱。

## 現況與問題

- 物品副本與能力等級使用 `arrow.up`／`arrow.down`；勢力層級與側邊欄設定列使用 `chevron.up`／`chevron.down`。四處都是把目前列移動一格，字形卻不一致。
- 物品副本有「上移副本／下移副本」help；其他三處的純圖標控制沒有對應的明確操作名稱。各處目前按鈕 style、禁用條件和 action 不同，不能一起改成新的通用行為。

## 範圍與非目標

- 涵蓋上述四組共八個純圖標控制，以及它們的語意圖標與 help／accessibility 名稱。
- 不改按鈕位置、大小、style、禁用條件、列排序演算法、拖曳重排、資料保存或 schema。
- 展開／收合的 chevron、AI 送出箭頭、匯出／匯入圖標等用途不同，不納入。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求相同功能使用相同圖標與敘述文字。 |
| U | pending | 提案如下，待使用者核定既有 chevron 是否改為箭頭。 |
| I | pending | U 核定後再以 `SailuneSymbol.moveUp`／`.moveDown` 和共用文案接線；原各處 action、style 與禁用條件保留。 |

## UI 提案

| 畫面 | 上移／下移圖標 | help 與輔助功能名稱 |
|---|---|---|
| 物品副本 | 保留 `arrow.up`／`arrow.down` | 保留「上移副本／下移副本」 |
| 能力等級 | 保留 `arrow.up`／`arrow.down` | 「上移能力等級／下移能力等級」 |
| 勢力層級 | `chevron.up`／`chevron.down` 改為 `arrow.up`／`arrow.down` | 「上移勢力層級／下移勢力層級」 |
| 側邊欄設定列 | `chevron.up`／`chevron.down` 改為 `arrow.up`／`arrow.down` | 「上移側邊欄項目／下移側邊欄項目」 |

文字線框：`[列內容] [↑ 上移] [↓ 下移]`；圖標仍留在原列尾和原按鈕位置，游標提示與輔助功能讀出上述名稱。上下邊界列維持原禁用狀態。

## 驗收條件

1. 四處相同操作共用一組上下移動語意圖標；展開箭頭等不同用途不受影響。
2. 八個控制均有對應 help 與 accessibility label；名稱中的操作詞一致，對象可區分。
3. 四處原按鈕 style、位置、禁用條件、action、保存與拖曳重排不變。
4. 核對 Light／Dark、實際命中與 VoiceOver；未能實測的項目記為未驗收。
