> 狀態：closed

> 工作單位：為三處 AI 回應解碼 fallback 加入分支明確的診斷，保留現有結果。

## 現況與範圍

- `SailuneAIClient` 的 backend JSON 回應、Gemini interaction 外殼與其中 model output JSON 都用 `try?` 折疊解碼錯誤。
- 三處各改為 `do/catch`，失敗時以 private OSLog 記錄錯誤類型及描述；不記錄回應本文、URL、API key 或使用者 prompt。
- 失敗後的 `nil`、原 `invalidResponse` 錯誤與其他 API 行為維持。空答案檢查、HTTP 狀態及裝置端路徑不改。

## 完成條件

- 三個解碼點可區分於診斷，fallback 與既有錯誤出口不變。
- 主機無簽章 macOS Debug build 與 `git diff --check` 通過；不新增或執行 XCTest。

## 結果與驗證

- 三處解碼已分別記錄 backend、Gemini interaction 和 Gemini model output 的失敗；錯誤描述使用 private privacy，不記錄原始回應。
- 原失敗後 `nil`、`invalidResponse` 及空答案檢查不變。主機無簽章 Debug build 與 `git diff --check` 通過；`try?` 靜態命中由 13 降至 10。
- 未執行 XCTest、故障注入或實際 AI 服務呼叫。
