# V9.1ar 親屬關係搜尋欄共用化

> 狀態：active；固定 ID V9-0897；R approved、U approved、I approved（使用者同意具體提案，並已要求依固定清單完成剩餘項目）。

## 現況與範圍

`KinshipGraphViews.swift` 的「搜尋角色」是圓角原生 TextField，與「篩選」Picker 及網路檢視的縮放按鈕同列。現有 `SailuneSearchField` 帶搜尋圖標、清除鈕、背景與外層 12／10 pt padding；直接替換會改變同列寬度與命中位置。本工作只處理固定 ID V9-0897，不改角色篩選、圖譜平移／縮放、搜尋結果或資料。

## U 提案

同一橫列維持「搜尋角色｜篩選｜縮小｜放大」順序；搜尋欄改用共用搜尋內部圖標、清除行為與背景，針對密集橫列新增具名 compact variant，移除共用元件的外層 12／10 pt padding，以父列原有 `.padding(.horizontal)` 和 `.padding(.bottom, 8)` 負責定位。實際寬度由 HStack 可用尺寸決定，不加固定 offset。文字、過濾及 Binding 不變。需在一般與最小視窗寬度驗收搜尋、清除、Picker、縮放按鈕均可點擊且不重疊。

## I 與驗收

U 核定後，核對 SharedUI 呼叫者尺寸依賴，再加 compact variant 並接入本 ID；Debug build、原有搜尋過濾與不同視窗寬度 hit-test／CJK／Light／Dark 實際驗收後才能關閉。2026-09-25 已按核定方案接線，主機無簽章 Debug build 通過；一般／最小視窗命中、CJK、Light／Dark 仍待實際驗收。
