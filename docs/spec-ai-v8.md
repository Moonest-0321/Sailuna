# V8 AI 助手：可選節次的裝置端聊天

> 狀態：V8.2 閱讀範圍、固定設定分析、角色一致性比較及送出前容量檢查已實作；無簽章 Debug build 與受影響 Swift parse 通過，隔離資料 UI 驗收待完成。既有角色資料查詢／單節整理的隔離資料 UI 驗收仍待完成。

## 使用流程與畫面

1. 作者在書籍工作區點擊工具列「AI 助手」。開啟側欄本身不讀取正文。
2. 輸入框左側「＋」的「加入閱讀範圍…」可選單節、單卷或全書。選取後，輸入區顯示待加入的範圍名稱，可在送出前移除。未選閱讀範圍時仍是一般聊天。
3. 作者輸入自然語言問題並送出。附帶閱讀範圍時，App 先提交編輯器待存文字，再依原卷／節順序擷取範圍內非空節次的最新純文字快照，連同問題加入目前對話；該則訊息可展開查看已加入的正文。失效範圍或沒有可讀正文時不送出。一般聊天不讀取任何正文。
4. 側欄顯示載入、取消或失敗狀態，成功時顯示文字回覆。本階段不自動產生或驗證引文。
5. AI 與設定集側欄可獨立開關。同時開啟時，從左到右為「編輯器／大綱 → AI 助手 → 設定集」。
6. 側欄標題列的「切換對話」打開目前書籍的對話清單，可新建、切換或刪除整段對話。刪除前顯示永久刪除確認；最後一段刪除後建立空白對話。切換／刪除目前對話會取消正在生成的回覆。
7. 一般聊天若明確詢問角色資料（例如「小明的資料」），App 只在目前書籍以角色本名／別名尋找角色，並將該角色已填寫的既有分類資料附加於當則訊息；作者可展開查看。無匹配或多位角色同長度匹配時顯示錯誤，不傳送其他角色資料。
8. 輸入框「＋」選單中的「角色資訊整理…」可選一個節次、一個角色及一或多個現有角色分類。送出後 AI 僅依該節原文，按選定分類整理該角色在本節提及的資訊；未提及的分類需標示未提及。該則訊息可展開檢視所送資料與模板。

## 資料與服務邊界

- App 使用 Apple Foundation Models 的 `SystemLanguageModel.default`，不需金鑰或本機後端。一般聊天提示只含對話；明確選取閱讀範圍後，該則使用者訊息才帶標題與純文字內文快照。未選取的正文範圍、設定集、其他書籍及 SwiftData model 不進入提示。
- 角色資料查詢是明確的例外：僅當提示符合角色資料查詢用語時，從目前書籍取出匹配角色現有資料，作為該則訊息的附件；角色分類包含基本資訊、別名、勢力、能力、外觀、心理、物品、關係及事件等已存在資料。模板整理附件僅含所選節次純文字、目標角色名稱與所選分類，不附帶既有角色設定，避免把設定誤作本節證據。
- 對話與所選內文快照依書籍 UUID 存於 Application Support 的 `Sailune/AI Conversations/<書籍 UUID>.json`，不寫入正文、設定集或 SwiftData。關閉 App 後保留，書籍間隔離；完整備份、還原及刪書清理包含對話檔。舊備份無對話檔仍可還原，並清除還原前的對話。已送出的快照可供該段後續對話參照，不會因原文再編輯而暗中更新。
- 第一則提問的前 32 字作為對話名稱，空白對話顯示「新對話」。切換時清除尚未送出的草稿與待加入節次；對話讀取或儲存失敗會顯示錯誤，不覆蓋損壞的既有檔案。
- 裝置不支援、Apple Intelligence 未啟用或模型未準備好時顯示對應錯誤。節次或對話超出裝置端上下文長度時顯示明確錯誤，不自動截短或轉送雲端。
- 角色資料回覆只在附件所含設定有記載時作答；章節整理只依所選節次，不推斷未提及內容。角色整理結果只留在聊天，不寫入角色設定或正文，不新增 schema。
- 首頁 Gemini 設定與模型選擇入口已移除，App 不再依舊 provider 偏好呼叫 Gemini。既有本機開發後端與先前保存的個人金鑰資料不作本輪刪除；它們不參與目前使用流程。Google 登入仍暫緩。

## 驗收條件

- 工具列順序正確；AI 與設定集側欄可各自開關，設定集始終在 AI 右側。
- 未選節次時不讀正文；選節後只擷取作者指定的一節，且可選非當前編輯節次。空節與失效選擇顯示錯誤，不送出。
- 選中的節次在輸入區與送出後的對話可辨識，作者能移除選擇並維持一般聊天。AI 不修改作者資料。
- 可建立、切換、確認刪除對話；各段訊息互不混入，重開 App 後仍按書籍保留，備份／還原與刪書行為一致。
- 裝置端通路不需要金鑰或網路請求；首頁沒有 Gemini 使用入口。

## 待確認的後續需求

- 一次選多節、節次內容變更後的重新擷取、非角色設定資料類型查詢與線上 Apple 模型接入，均須另立工作單確認。

## V8.2 閱讀範圍、固定分析與角色比較

1. AI 輸入框「＋」可選單節、單卷或全書作為閱讀範圍。範圍加入輸入區後，可輸入一般問題，或直接按「生成摘要」；一般聊天若未選範圍，不附加正文。
2. 「設定分析…」可選閱讀範圍、目前書籍中已存在的一個角色／物品／能力／勢力及該資料目前已有的分析維度。選取完成按「開始分析」即使用固定提示執行，不提供自訂提示欄。分析附件保留所選正文及目標設定快照，供展開檢視。
3. 「角色比較…」可選閱讀範圍、目前書籍中一個既有角色及一或多個既有角色分類，按「開始比較」直接執行。只列正文有明確提及且可核對的設定出入；正文未提及的設定不列為矛盾。附件保留比較所需的正文及所選分類快照。
4. 以上功能只讀目前書籍與明確選取的目標／範圍，結果只進入 AI 對話，不修改正文、角色、物品、能力或勢力；不新增 SwiftData 欄位或設定分類。
5. 裝置端送出前會計算完整固定提示、對話歷史及附件 token 數，並為回覆保留上下文空間。超出目前模型容量時顯示內容過長，該次訊息不存入對話也不送出；不自動拆段、截短或改送雲端。實際容量依 Apple Foundation Models 執行時提供的 context size 及 token-count API 判斷。
