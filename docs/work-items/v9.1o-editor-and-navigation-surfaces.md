# V9.1o 故事背景編輯欄與導覽卡片表面色

> 狀態：closed（四處同用途背景已接入語意 token）
>
> 工作單位：把故事背景編輯欄及可點擊導覽卡片的重複背景色，依用途集中在共用 UI theme，保留既有色值和形狀。

## 現況與完成條件

- `OutlineViews` 的兩個故事背景 TextEditor 使用相同 `Color.secondary.opacity(0.08)`、8 pt 圓角；書籍總覽的故事背景卡片與大綱摘要卡片也使用該色及 10 pt 圓角。
- 新增 `storyBackgroundEditorSurface`、`navigationCardSurface` 兩個語意 token；既有 `searchFieldSurface` 雖同色，保留不同用途名稱。三者共用同一色值來源，四個呼叫點只改背景顏色引用。
- 原文字、Binding、padding、圓角、frame、點擊與 action 順序保持。啟動錯誤內容、AI 訊息、登入列也使用 `0.08`，但語意不同，暫不接入上述 token。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者明確要求背景顏色與重複 UI 性質集中為同一程式碼調用。 |
| U | not_applicable | 僅將相同顏色值改為語意引用，原形狀、尺寸與互動不變。 |
| I | approved | 新增 theme aliases 並替換四處既有背景值；不改其他 UI。 |

## 驗證與限制

- 2026-09-24：主機無簽章 macOS Debug build 與 `git diff --check` 通過；四處呼叫點已靜態核對。未執行程式測試或 Light／Dark GUI 驗收。
- 其他 `Color.secondary.opacity(...)` 用途需按語意逐一分類，不以數值相同作全專案批量替換。
