# V9.1a 共用 UI 基礎定義

> 狀態：closed（共用基礎與既有共享型別歸位完成）
>
> 工作單位：建立未接入畫面的共用語意資源與設計 tokens。

## 目標與完成條件

- 集中定義操作圖標、通用操作文字、surface／編輯器色彩、間距與控制尺寸，供 V9.1 `AppearanceRow` 及後續畫面使用。
- 符號名稱與文字 key 有明確語意；刪除資料、解除關聯、關閉和取消分開命名。
- 把已跨畫面使用的 `InsetTextEditor` 和 `PlanningActionStyle` 移到共用 UI 區域，保持其程式內容與呼叫 API，讓原有呼叫點使用集中定義。
- 新增／移動檔案可被 Xcode 專案編入，無可見畫面或資料行為變動；記錄建置與 `git diff --check` 結果。

## 範圍

- 新增 `Sailune/SharedUI/SailuneUIFoundation.swift`、`Sailune/SharedUI/PlanningActionStyle.swift` 與 `Sailune/Localizable.xcstrings`；從 feature 檔移出相同的 `InsetTextEditor`／`PlanningActionStyle` 宣告。
- 沿用 `AppTheme.swift` 既有 `appBackground`、`workspacePanelBackground`，一般編輯器表面與描邊 token 採 `InsetTextEditor` 既有色彩值作起點。
- 本批不改任何 View 呼叫點、控制位置、命中區、持久化或領域操作。`AppearanceRow` 的 UI 接入由 `v9.1-shared-ui-pilot.md` 管理。

## 決策與理由

- 先定義可重用的語意 key 與 tokens，再由 V9.1 試行畫面驗證 API；現有跨畫面使用的兩個型別只移動宣告位置，不改操作語意。
- 共用語意把 `.delete` 和 `.removeAssociation`、`.close` 和 `.cancel` 分開；相同圖形可以服務不同操作，但呼叫端須明確指定語意。
- 依實際程式 action 再區分 `.deleteTime`、`.removeHolder`、`.removeSelection`、`.zoomIn` 與 `.selected`；詳見 V9 整體規劃的圖標語意核對表。已批准的 Timeline 日期刪除 `xmark` 保留為語意例外。
- 既有使用者工作樹中 `docs/work-items/current.md` 仍追蹤 V8.2。本工作以獨立檔案保存 V9.1a 的 R／U／I，不覆寫 V8.2 工作單。

## R／U／I

| 關卡 | 狀態 | 依據 |
|---|---|---|
| R | approved | 使用者要求完成 V9，已確認同功能圖標／文字與共用色彩／尺寸來源；本單限無畫面接入的基礎定義。 |
| U | not_applicable | 本批只新增尚未使用的資源與 tokens，沒有可見畫面或互動變更。 |
| I | approved | 使用者指示繼續完成版本；以上範圍、檔案與驗證方式已具體列出。 |
