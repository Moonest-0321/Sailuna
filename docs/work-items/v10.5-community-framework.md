# V10.5 社群介面骨架

> 狀態：active
>
> R：使用者回覆「R」核准。U：使用者回覆「U」核准上述版面。I：使用者先前明確要求依指定內容加搜尋框並先做論壇框架，授權直接實作。
>
> 範圍：搜尋模板頁上方輸入框；論壇頂欄橫向分類導覽與空內容頁面骨架。

## 已決定

- 「搜尋模板」分頁在分頁列下方顯示共用搜尋欄，提示文字為「搜尋模板」。
- 本階段只建立輸入框外觀，不接搜尋目錄、網路服務或搜尋結果；使用者要求先照指定呈現搜尋框。
- 論壇先呈現五個討論區：官方公告、寫作交流、作品交流、帆夢交流、功能建議。
- 選擇討論區可切換其標題與空內容狀態；不建立假貼文。
- 帳號、登入、發文、回覆、公開資料服務與內容管理延後處理。

## UI 骨架

- 論壇主頁頂欄橫向排列五個討論區按鈕，內容區顯示目前討論區與空內容狀態。
- 模板搜尋框置於「搜尋模板」頁面的上方、分頁列下方；離開該分頁時不顯示。
- 沿用既有共用搜尋欄與 theme，不新增圖標語意或資料模型。

## 驗收條件

- 切到「搜尋模板」時可見上方搜尋框；切回「我的模板」時隱藏。
- 論壇頂欄五個討論區均可選取；下方標題隨選取項目切換，空資料時不出現示例貼文。
- 不新增登入、資料庫、網路請求、發文或回覆流程。

## 實作紀錄

- 已完成模板搜尋頁上方搜尋欄與論壇頂欄橫向分類骨架；受影響 Swift 檔案 frontend parse、git diff --check 與主機環境無簽章 Debug build 通過。沙盒內 build 曾因 SwiftData macro server malformed response 失敗；未執行 XCTest 或 GUI 驗收。

## 使用者版面修正（U 更新）

- 使用者要求論壇分類改為頂欄橫向排列，模板搜尋框移到上方；已依指示調整。

- 使用者於 2026-09-26 要求分類改為頂欄橫排、搜尋框移到上方；修正後 Debug build 通過。
